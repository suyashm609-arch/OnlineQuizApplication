
# Online Quiz Application

A desktop-based quiz application developed using Java Swing. Users can answer multiple-choice questions and view their final score and percentage.

## Features

- Simple graphical user interface
- Multiple-choice questions with four options
- Answer validation
- Automatic score calculation
- Final score and percentage display

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)

## Project Structure

```text
OnlineQuizApplication/
├── src/
│   └── QuizApp.java
├── .gitignore
└── README.md
```

## How to Run

1. Install the Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal inside the `src` folder.
4. Compile the program:

   ```bash
   javac QuizApp.java
   ```

5. Run the application:

   ```bash
   java QuizApp
   ```
